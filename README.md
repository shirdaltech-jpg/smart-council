# شورای هوشمند (AI Council)

این برنامه یک میز کار دسکتاپ است. چند مدل هوش مصنوعی (با کلید API خودت) مثل اعضای یک شورا روی پروژه‌ی تو کار می‌کنند.

**تو چیکار می‌کنی؟** هدف پروژه را می‌نویسی و پوشه‌ی آن را انتخاب می‌کنی.

**شورا چیکار می‌کند؟** هدف را تحلیل می‌کند، به تسک تقسیم می‌کند، فایل و کد می‌سازد، بعد یک مدل دیگرِ مستقل کار را بازبینی می‌کند و در پایان گزارش می‌دهد.

**قاعده‌ی اصلی:** متنِ مدل هرگز دلیل نمی‌شود. برنامه محتوای واقعیِ فایل‌ها را بررسی می‌کند و یک تسک را فقط وقتی «تأییدشده» می‌گوید که شاهدش در ورک‌اسپیس وجود داشته باشد.

**ایمنی:** برنامه فقط داخل پوشه‌ی پروژه کار می‌کند. فرمان اجرا نمی‌کند، چیزی نصب نمی‌کند، بیرون از پوشه دسترسی نمی‌گیرد، و برای حذف فایل از تو اجازه می‌خواهد.

**داده:** همه‌چیز روی همان دستگاه تو در IndexedDB می‌ماند. کلید API فقط در localStorage است و به هیچ لاگ یا پایگاه‌داده‌ای راه نمی‌یابد.
